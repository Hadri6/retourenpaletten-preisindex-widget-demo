# Retourenpaletten-Preisindex – Widget-Demo

Demo page showing how to embed the open **Retourenpaletten-Preisindex** chart published by
[RetourenDirekt](https://retourendirekt.de/) (Auctum GmbH, Schorfheide near Berlin) in any website.

- Index page: https://retourendirekt.de/preisindex
- Methodology: https://retourendirekt.de/preisindex/methodik
- Data (CSV/JSON): https://retourendirekt.de/preisindex/daten
- Embeddable chart: https://retourendirekt.de/preisindex/embed

Embed snippet:

```html
<iframe src="https://retourendirekt.de/preisindex/embed" title="Retourenpaletten-Preisindex – Diagramm"
        width="100%" height="560" loading="lazy" style="border:0"></iframe>
<p>Quelle: <a href="https://retourendirekt.de/preisindex">Retourenpaletten-Preisindex</a> (CC BY 4.0)</p>
```
